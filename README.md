# Immersive Bicycle Mod for Gen1Recomp
**v0.1.30** · by **WizzStar**

> Your bicycle dream becomes reality. And if you don’t need it anymore, just dump it somewhere.

**Repo:** [PKMN-G1R-Immersive-Bicycle-Mod](https://github.com/WizzStar/PKMN-G1R-Immersive-Bicycle-Mod)

## 🎨 Art
- Parked bicycle sprites are hand-drawn by me

## ✨ Features
- **Door Valet** — Park at doors, then walk in
- **Dismount** — Stand still + **B**
- **Bike Throw** *(WIP)* — Hold direction + **B**
- **Mount** — **A** on parked bike
- **Bag Recall** — Bag **BICYCLE** *(very buggy)*
- **Palette Match** — OG Color / ADVANCED safe

## 📦 Installation
1. Download `wizzstar-immersive-bicycle-mod-0.1.30.zip`
2. Gen1Recomp → MODS → enable → restart
